# Gtk.Windows.Forms.sln — projects

This documents the projects in [Gtk.Windows.Forms.sln](Gtk.Windows.Forms.sln) — **the product solution** (the shippable libraries plus their tests). The three PoC sample apps (`GtkWinFormsApp`, `GtkSystemWinFormsApp11`, `AutoClosingMessageBoxApp`, grouped under the `PoC` solution folder) are intentionally **not** covered here. The separate `PrepareProjects.sln` build pipeline is documented in [PrepareProjects/PrepareProjects.md](PrepareProjects/PrepareProjects.md).

> Reminder: the library source under `Gtk.Windows.Forms/` and `Gtk.Drawing/` is generated by the prepare pipeline and can be overwritten — see [CLAUDE.md](CLAUDE.md).

## Solution layout

The solution organizes projects into these solution folders:

| Solution folder | Contents |
|---|---|
| _(root)_ | The shippable libraries: `Gtk.Windows.Forms`, `Gtk.Drawing`, `Gtk.Windows.FormsDesigner`, `System.Resources.Extensions`, `Gtk.Windows.Extensions` |
| `Tools` | `ResxProcessor` |
| `Tests` | `Gtk.Windows.Forms.Tests`, `Gtk.Drawing.Tests`, `Gtk.Windows.FormsDesigner.Tests`, `ResxProcessor.Tests`, `AutoClosingMessageBox.Tests` |
| `PoC` | Sample apps — **not documented here** |
| `Solution Items` | `.editorconfig`, `Directory.Build.Props`, `Directory.Nuget.Props`, `Nuget.Config`, `ReadMe.md` |

Common conventions across the shippable libraries: `TargetFramework` = `netstandard2.0` (intentionally decoupled from any specific .NET version), strong-named with `GtkForms.snk`, `GeneratePackageOnBuild=true` with packages emitted to `Packages/`, versioned from `$(VersionPrefix).$(VersionSuffix)` (set centrally in `Directory.Build.Props` / `Directory.Nuget.Props`), and each imports the `Net4x.NuGetUtility` props/targets. Note the **NuGet package IDs differ from the project names** (project `Gtk.*` → package `Gtk.*`).

## Shippable libraries

### Gtk.Windows.Forms → package `Gtk.Windows.Forms`
[Gtk.Windows.Forms/Gtk.Windows.Forms.csproj](Gtk.Windows.Forms/Gtk.Windows.Forms.csproj)

The core library: a WinForms-compatible API surface implemented on top of GtkSharp. Public types mirror `System.Windows.Forms`; GTK-backed implementations live under `GtkControls/` and `GtkSystem/`. Image assets are `EmbeddedResource`s under `Resources/System/`; localized message/resource strings are compiled from `.resx` (zh-Hans, en, it, fr, de, es).

- **References:** `GtkSharp` ($(GtkSharpLatestVersion).*), `System.Memory`, `System.Resources.Extensions` (the `Gtk.Resources.Extensions` package), `xunit.extensibility.core`; project references to `Gtk.Drawing` and `Gtk.Windows.FormsDesigner`.
- **Packaging extras:** ships MSBuild `build/` props+targets (`Gtk.Windows.Forms.props`/`.targets`), `content/` source files (`System.ComponentModel.cs`, `System.Resources.ResourceManager.cs`), and bundles the built `ResxProcessor` under `tools/`.
- `InternalsVisibleTo` → `Gtk.Windows.Forms.Tests`.

### Gtk.Drawing → package `Gtk.Drawing`
[Gtk.Drawing/Gtk.Drawing.csproj](Gtk.Drawing/Gtk.Drawing.csproj)

The `System.Drawing` compatibility shim (brushes, `Matrix`, `StringFormat`, image types, etc.) over GTK/Cairo. Split out of the Forms library by the prepare pipeline so drawing can be consumed independently. Links a few `System.Diagnostics.CodeAnalysis` attribute source files from the Forms project.

- **References:** `GtkSharp`, `System.Memory`, `System.Resources.Extensions`.
- `InternalsVisibleTo` → `Gtk.Windows.Forms`, `Gtk.Windows.Forms.Tests`, `Gtk.Drawing.Tests`.

### Gtk.Windows.FormsDesigner → package `Gtk.Windows.FormsDesigner`
[Gtk.Windows.FormsDesigner/Gtk.Windows.FormsDesigner.csproj](Gtk.Windows.FormsDesigner/Gtk.Windows.FormsDesigner.csproj)

Design-time support that lets the Visual Studio WinForms designer open forms built on this framework. Referenced by the Forms library and shipped as its own package with `build/` props+targets.

- **References:** `Microsoft.Build.Framework`, `Microsoft.Build.Utilities.Core` (MSBuild integration).
- RootNamespace `Gtk.Windows.FormsDesigner`.

### Gtk.Resources.Extensions → package `Gtk.Resources.Extensions`
[Gtk.Resources.Extensions/Gtk.Resources.Extensions.csproj](Gtk.Resources.Extensions/Gtk.Resources.Extensions.csproj)

An **intentionally empty** assembly whose `AssemblyName` is literally `System.Resources.Extensions`, so it displaces Microsoft's assembly of that name in an application's output folder — the working ResX reader lives in the Forms library under `GtkSystem/Resources/Extensions/`. [README.md](Gtk.Resources.Extensions/README.md) explains this to package consumers and is packed at the package root. Minimal csproj — source and packaging metadata are supplied by the prepare pipeline (`SystemResourcesExtensionsProjectHandler`), which wipes and re-emits the whole project directory on every run.

- Packs on build into `Packages/` like its siblings. It did not until the packaging metadata was moved into the pipeline handler, so `Gtk.Resources.Extensions` was never actually published.

### Gtk.Windows.Extensions → package `Gtk.Windows.Extensions`
[Gtk.Windows.Extensions/Gtk.Windows.Extensions.csproj](Gtk.Windows.Extensions/Gtk.Windows.Extensions.csproj)

Additions to the `System.Windows.Forms` surface that are not part of the real WinForms API, layered on the Forms library and kept out of it (excludes its own `Resources/` and `System.Windows.Forms/` folders from compilation). `Nullable=annotations`. Hand-maintained — the prepare pipeline does not generate it.

- **Ships:** `AutoClosingMessageBox` ([System/Windows/Forms/AutoClosingMessageBox.cs](Gtk.Windows.Extensions/System/Windows/Forms/AutoClosingMessageBox.cs)) — install it with `AutoClosingMessageBox.Install(timeout)`, which calls `MessageBox.ReplaceInstance(IMessageBox)` in the Forms library.
- **Project reference:** `Gtk.Windows.Forms`.
- `InternalsVisibleTo` → `Gtk.Windows.Forms.Tests`.
- Consumes `Gtk.Windows.Forms`' `internal` types (`NonStaticMessageBox`) via that library's matching `InternalsVisibleTo` grant.

## Tools

### ResxProcessor
[ResxProcessor/ResxProcessor.csproj](ResxProcessor/ResxProcessor.csproj)

A `WinExe` (`net8.0`) utility for resource (.resx) processing. It is **not** published as a standalone package; instead its build output is bundled into the `Gtk.Windows.Forms` package under `tools/` (see that project's csproj) and invoked as part of the framework's resource handling.

- `InternalsVisibleTo` → `ResxProcessor.Tests`.

## Test projects

All test projects use **xUnit** with `Microsoft.NET.Test.Sdk` and `coverlet.collector`, and are non-packable (`IsPackable=false`).

| Test project | TFM | Under test / references | Notes |
|---|---|---|---|
| [Gtk.Windows.Forms.Tests](Gtk.Windows.Forms.Tests/Gtk.Windows.Forms.Tests.csproj) | `net10.0` | `Gtk.Windows.Forms` + `Gtk.Drawing` (extern alias `gtk`) | Uses `NSubstitute`; strong-named (matches the `InternalsVisibleTo` grants); links the `Content/System.*` source files. |
| [Gtk.Drawing.Tests](Gtk.Drawing.Tests/Gtk.Drawing.Tests.csproj) | `net10.0` | `Gtk.Drawing` (alias `gtk`) + `Gtk.Windows.Forms` | Uses `NSubstitute`; embeds `test.ico`; strong-named. |
| [Gtk.Windows.FormsDesigner.Tests](Gtk.Windows.FormsDesigner.Tests/Gtk.Windows.FormsDesigner.Tests.csproj) | `net8.0` | `Gtk.Windows.FormsDesigner` | Also references `Microsoft.Build.*` (designer/MSBuild integration). |
| [ResxProcessor.Tests](ResxProcessor.Tests/ResxProcessor.Tests.csproj) | `net8.0` | `ResxProcessor` | Strong-named. |
| [AutoClosingMessageBox.Tests](AutoClosingMessageBox.Tests/AutoClosingMessageBox.Tests.csproj) | `net10.0` | `AutoClosingMessageBoxApp` (a PoC app) | Tests a PoC app; not tied to a shippable library. |

The `gtk` extern alias on the `Gtk.Drawing` reference disambiguates its `System.Drawing`-shaped types from the real BCL `System.Drawing`.
