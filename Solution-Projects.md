# Net4x.Gtk.Windows.Forms.sln — projects

This documents the projects in [Net4x.Gtk.Windows.Forms.sln](Net4x.Gtk.Windows.Forms.sln) — **the product solution** (the shippable libraries plus their tests). The three PoC sample apps (`GtkWinFormsApp`, `GtkSystemWinFormsApp11`, `AutoClosingMessageBoxApp`, grouped under the `PoC` solution folder) are intentionally **not** covered here. The separate `PrepareProjects.sln` build pipeline is documented in [PrepareProjects/PrepareProjects.md](PrepareProjects/PrepareProjects.md).

> Reminder: the library source under `Net4x.Gtk.Windows.Forms/` and `Net4x.Gtk.Drawing/` is generated by the prepare pipeline and can be overwritten — see [CLAUDE.md](CLAUDE.md).

## Solution layout

The solution organizes projects into these solution folders:

| Solution folder | Contents |
|---|---|
| _(root)_ | The shippable libraries: `Net4x.Gtk.Windows.Forms`, `Net4x.Gtk.Drawing`, `Net4x.Gtk.Windows.FormsDesigner`, `Net4x.System.Resources.Extensions`, `Net4x.Gtk.Windows.Extensions` |
| `Tools` | `Net4x.ResxProcessor` |
| `Tests` | `Net4x.Gtk.Windows.Forms.Tests`, `Net4x.Gtk.Drawing.Tests`, `Gtk.Windows.FormsDesigner.Tests`, `Net4x.ResxProcessor.Tests`, `AutoClosingMessageBox.Tests` |
| `PoC` | Sample apps — **not documented here** |
| `Solution Items` | `.editorconfig`, `Directory.Build.Props`, `Directory.Nuget.Props`, `Nuget.Config`, `ReadMe.md` |

Common conventions across the shippable libraries: `TargetFramework` = `netstandard2.0` (intentionally decoupled from any specific .NET version), strong-named with `GtkForms.snk`, `GeneratePackageOnBuild=true` with packages emitted to `Packages/`, versioned from `$(VersionPrefix).$(VersionSuffix)` (set centrally in `Directory.Build.Props` / `Directory.Nuget.Props`), and each imports the `Net4x.NuGetUtility` props/targets. Note the **NuGet package IDs differ from the project names** (project `Net4x.*` → package `Gtk.*`).

## Shippable libraries

### Net4x.Gtk.Windows.Forms → package `Gtk.Windows.Forms`
[Net4x.Gtk.Windows.Forms/Net4x.Gtk.Windows.Forms.csproj](Net4x.Gtk.Windows.Forms/Net4x.Gtk.Windows.Forms.csproj)

The core library: a WinForms-compatible API surface implemented on top of GtkSharp. Public types mirror `System.Windows.Forms`; GTK-backed implementations live under `GtkControls/` and `GtkSystem/`. Image assets are `EmbeddedResource`s under `Resources/System/`; localized message/resource strings are compiled from `.resx` (zh-Hans, en, it, fr, de, es).

- **References:** `GtkSharp` ($(GtkSharpLatestVersion).*), `System.Memory`, `System.Resources.Extensions` (the `Gtk.System.Resources.Extensions` package), `xunit.extensibility.core`; project references to `Net4x.Gtk.Drawing` and `Net4x.Gtk.Windows.FormsDesigner`.
- **Packaging extras:** ships MSBuild `build/` props+targets (`Gtk.Windows.Forms.props`/`.targets`), `content/` source files (`System.ComponentModel.cs`, `System.Resources.ResourceManager.cs`), and bundles the built `Net4x.ResxProcessor` under `tools/`.
- `InternalsVisibleTo` → `Net4x.Gtk.Windows.Forms.Tests`.

### Net4x.Gtk.Drawing → package `Gtk.Drawing`
[Net4x.Gtk.Drawing/Net4x.Gtk.Drawing.csproj](Net4x.Gtk.Drawing/Net4x.Gtk.Drawing.csproj)

The `System.Drawing` compatibility shim (brushes, `Matrix`, `StringFormat`, image types, etc.) over GTK/Cairo. Split out of the Forms library by the prepare pipeline so drawing can be consumed independently. Links a few `System.Diagnostics.CodeAnalysis` attribute source files from the Forms project.

- **References:** `GtkSharp`, `System.Memory`, `System.Resources.Extensions`.
- `InternalsVisibleTo` → `Net4x.Gtk.Windows.Forms`, `Net4x.Gtk.Windows.Forms.Tests`, `Net4x.Gtk.Drawing.Tests`.

### Net4x.Gtk.Windows.FormsDesigner → package `Gtk.Windows.FormsDesigner`
[Net4x.Gtk.Windows.FormsDesigner/Net4x.Gtk.Windows.FormsDesigner.csproj](Net4x.Gtk.Windows.FormsDesigner/Net4x.Gtk.Windows.FormsDesigner.csproj)

Design-time support that lets the Visual Studio WinForms designer open forms built on this framework. Referenced by the Forms library and shipped as its own package with `build/` props+targets.

- **References:** `Microsoft.Build.Framework`, `Microsoft.Build.Utilities.Core` (MSBuild integration).
- RootNamespace `Gtk.Windows.FormsDesigner`.

### Net4x.System.Resources.Extensions → package `Gtk.System.Resources.Extensions`
[Net4x.System.Resources.Extensions/Net4x.System.Resources.Extensions.csproj](Net4x.System.Resources.Extensions/Net4x.System.Resources.Extensions.csproj)

A reimplementation of `System.Resources.Extensions` (note `AssemblyName` is literally `System.Resources.Extensions`), providing ResX reading/serialization compatible with the framework. Consumed by the Forms and Drawing libraries via the `System.Resources.Extensions` package reference. Minimal csproj — source and packaging metadata are supplied by the prepare pipeline.

### Net4x.Gtk.Windows.Extensions → package `Gtk.Windows.Extensions`
[Net4x.Gtk.Windows.Extensions/Net4x.Gtk.Windows.Extensions.csproj](Net4x.Gtk.Windows.Extensions/Net4x.Gtk.Windows.Extensions.csproj)

Add-on extension helpers layered on the Forms library (excludes its own `Resources/` and `System.Windows.Forms/` folders from compilation). `Nullable=annotations`.

- **Project reference:** `Net4x.Gtk.Windows.Forms`.
- `InternalsVisibleTo` → `Net4x.Gtk.Windows.Forms.Tests`.

## Tools

### Net4x.ResxProcessor
[Net4x.ResxProcessor/Net4x.ResxProcessor.csproj](Net4x.ResxProcessor/Net4x.ResxProcessor.csproj)

A `WinExe` (`net8.0`) utility for resource (.resx) processing. It is **not** published as a standalone package; instead its build output is bundled into the `Gtk.Windows.Forms` package under `tools/` (see that project's csproj) and invoked as part of the framework's resource handling.

- `InternalsVisibleTo` → `Net4x.ResxProcessor.Tests`.

## Test projects

All test projects use **xUnit** with `Microsoft.NET.Test.Sdk` and `coverlet.collector`, and are non-packable (`IsPackable=false`).

| Test project | TFM | Under test / references | Notes |
|---|---|---|---|
| [Net4x.Gtk.Windows.Forms.Tests](Net4x.Gtk.Windows.Forms.Tests/Net4x.Gtk.Windows.Forms.Tests.csproj) | `net10.0` | `Net4x.Gtk.Windows.Forms` + `Net4x.Gtk.Drawing` (extern alias `gtk`) | Uses `NSubstitute`; strong-named (matches the `InternalsVisibleTo` grants); links the `Content/System.*` source files. |
| [Net4x.Gtk.Drawing.Tests](Net4x.Gtk.Drawing.Tests/Net4x.Gtk.Drawing.Tests.csproj) | `net10.0` | `Net4x.Gtk.Drawing` (alias `gtk`) + `Net4x.Gtk.Windows.Forms` | Uses `NSubstitute`; embeds `test.ico`; strong-named. |
| [Gtk.Windows.FormsDesigner.Tests](Gtk.Windows.FormsDesigner.Tests/Gtk.Windows.FormsDesigner.Tests.csproj) | `net8.0` | `Net4x.Gtk.Windows.FormsDesigner` | Also references `Microsoft.Build.*` (designer/MSBuild integration). |
| [Net4x.ResxProcessor.Tests](Net4x.ResxProcessor.Tests/Net4x.ResxProcessor.Tests.csproj) | `net8.0` | `Net4x.ResxProcessor` | Strong-named. |
| [AutoClosingMessageBox.Tests](AutoClosingMessageBox.Tests/AutoClosingMessageBox.Tests.csproj) | `net10.0` | `AutoClosingMessageBoxApp` (a PoC app) | Tests a PoC app; not tied to a shippable library. |

The `gtk` extern alias on the `Net4x.Gtk.Drawing` reference disambiguates its `System.Drawing`-shaped types from the real BCL `System.Drawing`.
